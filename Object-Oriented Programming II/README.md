# INE5404 - Programação Orientada a Objetos II

Orientação a objetos em Python: herança, polimorfismo, composição, tratamento de erros, persistência em arquivo, interface gráfica e princípios SOLID. Os trabalhos em grupo foram com o [Augusto Schweitzer](https://github.com/AugustoSchw), o [Rodrigo Schwartz](https://github.com/R0drigoSchwartz) e o [Tom Hunt](https://github.com/tmphnt).

O trabalho final foi o **The Lost Key**, um jogo que juntava tudo que vimos na disciplina. O jogo vive no próprio repositório e entra aqui como submódulo `Final Project`.

Repositório do jogo: **[The Lost Key](https://github.com/tmphnt/The-Lost-Key)**
