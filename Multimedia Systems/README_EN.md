# INE5431 - Multimedia Systems

**Team:** Pedro Henrique Gimenez and Tom Pereira Hunt
**Professor:** Roberto Willrich

Four practicals on digital media processing in Python, built around the CUIF file format created in the course. Practicals 3 and 4 come with a Markdown report holding the math and the analysis of the results.

| Practical | What it does | Files |
| :-------: | :----------- | :---- |
| [Prática 1](./Prática%201/) | Written answers to the assignment. | [Pratica1_Respostas.pdf](./Prática%201/Pratica1_Respostas.pdf) |
| [Prática 2](./Prática%202/) | Image manipulation with Pillow: downscaling resolution, converting to grayscale and to binary, reducing the number of bits and splitting the RGB channels. | [praticaii.py](./Prática%202/praticaii.py) |
| [Prática 3](./Prática%203/) | Reading the BMP header, the CUIF format, computing MSE and PSNR, zip compression and quantization (CUIF.1 lossless and CUIF.2 lossy on the G and B channels). | [PraticaIII.py](./Prática%203/PraticaIII.py) · [RELATORIO.md](./Prática%203/RELATORIO.md) |
| [Prática 4](./Prática%204/) | Entropy compression with RLE, the YCbCr color space and a comparison of size and PSNR across CUIF.1, CUIF.2, CUIF.3 and CUIF.4. | [praticaIV.py](./Prática%204/praticaIV.py) · [RELATORIO.md](./Prática%204/RELATORIO.md) |
