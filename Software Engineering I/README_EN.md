# INE5417 - Software Engineering I

The final project was **Soma 10**, a two-player board game on 16 interconnected squares, where you win by collecting the most pieces through sums that add up to 10. The delivery went through the full process, from the requirements specification to the UML modeling and the game running in Python. The code lives in its own repository and comes in here as a submodule.

| Item | What it is |
|------|------------|
| [soma10](https://github.com/pehqge/soma10) | Submodule with the full game: code, documentation and dependencies. |

| [UML modeling](https://github.com/pehqge/soma10/tree/main/doc/modelagem) | Visual Paradigm `.vpp` project with the diagrams. |
