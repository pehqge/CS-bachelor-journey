# INE5406 - Digital Systems

Hardware design in VHDL on the FPGA board, with Victória Rodrigues on the group assignments. The first three practicals revolve around the SAD (sum of absolute differences) in two versions, v1 and v3, and the last one is a convolution module with a Gaussian filter.

## Graded assignments

| Assignment | Description |
| --- | --- |
| [Prática 1](./Prática%201) | 4x1 mux, 1x4 demux and a BCD to 7-segment decoder in two forms: logic expressions and case. With a report and the simulations. |
| [Prática 2](./Prática%202) | SAD v1 and v3 built from generic components (subtractor, adder, adder with overflow, mux and register). Report with the simulations and the delay analysis. |
| [Prática 3](./Prática%203) | SAD v1 and v3 with a testbench and golden model, using random stimuli generated in Python. |
| [Prática 4](./Prática%204) | Convolution module with a Gaussian filter, with Python scripts to generate and filter the test matrices. Includes the report and the RTL. |
