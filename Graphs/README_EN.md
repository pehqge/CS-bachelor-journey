# INE5413 - Graphs

Three practical assignments in Python, each implementing a block of graph algorithms and delivered with a PDF report. The code runs on top of a homegrown library: the `Grafo` and `Vertice` classes plus `auxiliar.py`, which reads `.net` files in Pajek format.

## Assignments

| Assignment | Report | Algorithms |
|---|---|---|
| [A1](Atividade%20A1) | [Relatorio.pdf](Atividade%20A1/Relatorio.pdf) | Graph representation, breadth-first search (BFS), Eulerian cycle (Hierholzer), Dijkstra and Floyd-Warshall. |
| [A2](Atividade%20A2) | [Relatorio.pdf](Atividade%20A2/Relatorio.pdf) | Strongly connected components (Kosaraju) and topological sort. |
| [A3](Atividade%20A3) | [Relatorio.pdf](Atividade%20A3/Relatorio.pdf) | Maximum flow (Edmonds-Karp), bipartite matching (Hopcroft-Karp) and vertex coloring (Lawler). |

Test graphs live in [Atividade A1/pequenas](Atividade%20A1/pequenas) (classic networks: karate, dolphins, lesmis, football, jazz) and [Atividade A3/python/dirigidos](Atividade%20A3/python/dirigidos) (directed networks, including maps of cities in Santa Catarina). A1 also has C++ versions of some of the algorithms.
